### 1. Dec 2025 End-Sem Q1(1): Finite Group Order Derivation
**Given**:
* (a) $a$ has order $15$ ($\{e, a, a^2, \dots, a^{14}\}$ has 15 distinct elements).
* (b) $G$ contains subgroup $H$ where every non-identity element has order 4, and $H$ has 5 non-identity elements $\implies |H| = 6$.
* (c) $b \notin H$ with $b^6 = e$, but no smaller positive power equals $e \implies$ $b$ has order 6.
* (d) No element in $G$ has order $> 30$.

**Group-Theoretic Derivation**:
1. By Lagrange's Theorem, the order of any element divides the order of the group:
   - Order of $a$ is $15 \implies 15 \mid |G|$.
   - Order of $b$ is $6 \implies 6 \mid |G|$.
   - Any element of order 4 in $G \implies 4 \mid |G|$.
2. Therefore, $|G|$ must be a multiple of $\text{LCM}(15, 6, 4)$:
   $$\text{LCM}(15, 6, 4) = \text{LCM}(3 \times 5, 2 \times 3, 2^2) = 2^2 \times 3 \times 5 = \mathbf{60}$$
   $$\implies |G| = 60 \cdot k \quad \text{for some integer } k \ge 1.$$
3. Condition (d) states no element has order $> 30$.
   If $G$ contains an element of order 15 ($a$) and an element of order 4 ($c$), if they commute or generate a cyclic subgroup, its order could be $\text{LCM}(15, 4) = 60 > 30$. Hence $G$ cannot be cyclic.
4. Minimal possible non-abelian group satisfying these order constraints:
   The alternating group $A_5$ has order 60, but elements of $A_5$ only have orders 1, 2, 3, 5 (no elements of order 4 or 6).
   The group $G = \mathbb{Z}_{15} \rtimes \mathbb{Z}_4$ or groups with order $|G| \in \{60, 120\}$ satisfy all conditions.
   $$\mathbf{|G| \in \{60, 120, 180, \dots\}}$$

### 2. Dec 2025 End-Sem Q1(2): Symmetric Difference Algebraic Structure $(2^X, \Delta)$
* **(a) Semigroup, Monoid, or Group?**:
  - **Closure**: For any $A, B \subseteq X$, $A \Delta B = (A \setminus B) \cup (B \setminus A) \subseteq X \implies A \Delta B \in 2^X$.
  - **Associativity**: $(A \Delta B) \Delta C = A \Delta (B \Delta C)$ holds for all subsets.
  - **Identity**: $\emptyset \in 2^X$ satisfies $A \Delta \emptyset = (A \setminus \emptyset) \cup (\emptyset \setminus A) = A \cup \emptyset = A$.
  - **Inverse**: For every $A \in 2^X$, $A \Delta A = (A \setminus A) \cup (A \setminus A) = \emptyset \cup \emptyset = \emptyset$.
  - Thus, **every element is its own inverse**.
  - **Conclusion**: $(2^X, \Delta)$ is a **GROUP**.
* **(b) Identity Element**: $\mathbf{\emptyset}$ (the empty set).
* **(c) Inverse**: The inverse of any subset $A$ is **$A$ itself** ($A^{-1} = A$).
* **(d) Final Classification**: An **Abelian Group of exponent 2** (an **Elementary Abelian 2-Group**, isomorphic to $(\mathbb{Z}_2)^{|X|}$).

### 3. Dec 2024 End-Sem Q3(a): Dual of Bipartite Planar Graph
**Theorem**: Let $G$ be a connected bipartite planar graph. What kind of graph is its dual $G^*$?
* **Proof**:
  1. A graph $G$ is **bipartite** if and only if it contains **no odd cycles** (Kőnig's Theorem).
  2. Every face $F_i$ in a planar graph is bounded by a cycle of edges in $G$.
  3. Since $G$ has no odd cycles, every cycle in $G$ has even length.
  4. Therefore, the boundary of every face in $G$ consists of an **even number of edges** ($\text{deg}(F_i) \ge 4$ and is even).
  5. In the dual graph $G^*$, every vertex $v_i^* \in V(G^*)$ corresponds to a face $F_i$ in $G$, and its vertex degree equals the face boundary length:
     $$\text{deg}_{G^*}(v_i^*) = \text{deg}_G(F_i)$$
  6. Consequently, **every vertex in $G^*$ has even degree**.
  7. By Euler's Theorem on Eulerian graphs, a connected graph in which every vertex has even degree has an **Eulerian circuit**.
* **Conclusion**: The dual graph $G^*$ is an **Eulerian Graph**.

### 4. Sept 2025 Mid-Sem Q1: Function Count to Relation Count
**Given**:
* Number of functions $f: X \to Y$ is $6,561$, with $|Y| = 3$.
* Formula for number of functions: $|Y|^{|X|} = 3^{|X|} = 6,561$.
  $$3^8 = 6,561 \implies |X| = 8$$
* $X$ is the power set of $A \implies |X| = 2^{|A|} = 8 = 2^3 \implies |A| = 3$.
* Let $n = |A| = 3$.
* **Binary Relations on $A$**:
  - Total number of binary relations $= 2^{n^2} = 2^{3^2} = 2^9 = \mathbf{512}$.
  - Reflexive relations (all 3 diagonal pairs $(a,a)$ present): $2^{n(n-1)} = 2^{3 \times 2} = 2^6 = \mathbf{64}$.
  - Irreflexive relations (no diagonal pairs $(a,a)$ present): $2^{n(n-1)} = 2^6 = \mathbf{64}$.
  - A relation cannot be simultaneously reflexive and irreflexive (they are mutually exclusive for $n \ge 1 \implies \text{Ref} \cap \text{Irref} = \emptyset$).
* **Relations that are Neither Reflexive Nor Irreflexive**:
  $$\text{Total} - (\text{Reflexive} + \text{Irreflexive}) = 512 - (64 + 64) = 512 - 128 = \mathbf{384}$$
* **Result**: **384 relations**.

### 5. Oct 2024 Mid-Sem Q3: Computer Course 50 Students (PIE)
**Given**:
* Total students $N = 50$.
* $|C| = 30$, $|P| = 18$, $|J| = 26$.
* $|C \cap P| = 9$, $|C \cap J| = 16$, $|P \cap J| = 8$.
* At least one language $|C \cup P \cup J| = 47$.

#### (a) How many students know none of these languages?
$$\text{None} = N - |C \cup P \cup J| = 50 - 47 = \mathbf{3\text{ students}}$$

#### (b) How many students know all three languages?
Using the Principle of Inclusion-Exclusion for 3 sets:
$$|C \cup P \cup J| = |C| + |P| + |J| - (|C \cap P| + |C \cap J| + |P \cap J|) + |C \cap P \cap J|$$
Substitute known values:
$$47 = 30 + 18 + 26 - (9 + 16 + 8) + |C \cap P \cap J|$$
$$47 = 74 - 33 + |C \cap P \cap J|$$
$$47 = 41 + |C \cap P \cap J|$$
$$|C \cap P \cap J| = 47 - 41 = \mathbf{6\text{ students}}$$
* **Result**: **6 students know all three languages**.
