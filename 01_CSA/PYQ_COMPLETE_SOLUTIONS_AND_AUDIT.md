### 1. Decimal to IEEE 754 Single-Precision (Sept 2026 Q1a)
**Problem**: Convert $-18.625$ into IEEE 754 single-precision floating point.
* **Step 1: Sign bit ($S$)**: The number is negative $\implies S = 1$.
* **Step 2: Binary conversion**:
  - Integer part $18$: $18 = 16 + 2 \implies 10010_2$.
  - Fractional part $0.625$:
    - $0.625 \times 2 = 1.25$ (integer 1)
    - $0.25 \times 2 = 0.5$ (integer 0)
    - $0.5 \times 2 = 1.0$ (integer 1)
    - $\implies 0.625_{10} = 0.101_2$.
  - True binary value: $-10010.101_2$.
* **Step 3: Normalization**:
  $$-10010.101_2 = -1.0010101_2 \times 2^4$$
  - Normalized fraction / mantissa: $M = 0010101$.
  - True exponent: $e = 4$.
* **Step 4: Biased Exponent ($E$)**:
  $$E = e + \text{Bias} = 4 + 127 = 131_{10} = 10000011_2$$
* **Step 5: 23-bit Mantissa ($F$)**:
  Pad $0010101$ with zeros to 23 bits:
  $$F = 00101010000000000000000$$
* **Step 6: Assemble 32-bit Word**:
  - Sign (1 bit): `1`
  - Exponent (8 bits): `10000011`
  - Mantissa (23 bits): `00101010000000000000000`
  - **Binary**: `1100 0001 1001 0101 0000 0000 0000 0000`
  - **Hexadecimal Representation**: `0xC1954000`

### 2. 8-Bit Signed 2's Complement Subtraction & Overflow (Sept 2026 Q2a)
**Problem**: Perform $(-85) - (+76)$ using 8-bit 2's complement arithmetic.
* **Operand 1: $-85$**:
  $+85 = 01010101_2 \implies 1\text{'s comp} = 10101010 \implies 2\text{'s comp} = 10101011_2$.
* **Operand 2: $+76$**:
  $+76 = 01001100_2$.
  Subtraction is performed as: $(-85) + (-76)$.
  Negate $+76$ to get $-76$:
  $-76 = 2\text{'s comp of } 01001100 = 10110011 + 1 = 10110100_2$.
* **Binary Addition**:
  ```text
    Carries:  1 0 1 0 0 0 0 0 0
               1 0 1 0 1 0 1 1   (-85)
             + 1 0 1 1 0 1 0 0   (-76)
             -----------------
             1 0 1 0 1 1 1 1 1
  ```
  - 8-bit Sum Result: `01011111` ($=+95_{10}$).
  - Carry into sign bit ($C_7$): `0`
  - Carry out of sign bit ($C_8$): `1`
* **Overflow Determination**:
  $$V = C_7 \oplus C_8 = 0 \oplus 1 = 1 \implies \mathbf{OVERFLOW\ OCCURRED!}$$
* **Justification**: The true mathematical result is $-85 - 76 = -161$. The minimum representable value in 8-bit 2's complement is $-128$ (range $[-128, +127]$). Since $-161 < -128$, an underflow occurs, producing an erroneous positive result ($+95$) due to sign reversal.

### 3. Carry Look-Ahead Adder Equations (Sept 2026 Q2b)
**Given**: $P_3 P_2 P_1 P_0 = 1011$, $G_3 G_2 G_1 G_0 = 0101$, $C_0 = 1$.
* **Signals**:
  $P_0 = 1, P_1 = 1, P_2 = 0, P_3 = 1$
  $G_0 = 1, G_1 = 0, G_2 = 1, G_3 = 0$
* **Carry Equations**:
  1. $C_1 = G_0 + P_0 C_0 = 1 + (1 \cdot 1) = 1 + 1 = \mathbf{1}$.
  2. $C_2 = G_1 + P_1 C_1 = 0 + (1 \cdot 1) = 0 + 1 = \mathbf{1}$.
  3. $C_3 = G_2 + P_2 C_2 = 1 + (0 \cdot 1) = 1 + 0 = \mathbf{1}$.
  4. $C_4 = G_3 + P_3 C_3 = 0 + (1 \cdot 1) = 0 + 1 = \mathbf{1}$.
* **Result**: $C_1 = 1, C_2 = 1, C_3 = 1, C_4 = 1$.

### 5. Expanding Opcode Calculations (Sept 2026 Q3b & Sept 2025 Q3a)

#### Case A: Sept 2026 Q3b (24-bit Instruction)
* Total instruction width = 24 bits.
* Number of instructions = 68 $\implies \text{Opcode bits} = \lceil \log_2 68 \rceil = \mathbf{7\text{ bits}}$ ($2^7 = 128 \ge 68$).
* Number of registers = 32 $\implies \text{Register bits} = \lceil \log_2 32 \rceil = \mathbf{5\text{ bits}}$ each.
* Two register fields = $2 \times 5 = \mathbf{10\text{ bits}}$.
* **Address field bits** = $24 - (\text{Opcode} + 2 \times \text{Reg}) = 24 - (7 + 10) = \mathbf{7\text{ bits}}$.
* **Max directly addressable locations** = $2^7 = \mathbf{128\text{ memory locations}}$.

#### Case B: Sept 2025 Q3a (28-bit Instruction, Expanding Opcode)
* Instruction width = 28 bits; address fields = 10 bits each.
* **Two-Address Format**: Opcode width = $28 - (10 + 10) = 8$ bits.
  Total possible patterns = $2^8 = 256$.
  Used two-address instructions = 249.
  Unused patterns = $256 - 249 = 7$ patterns.
* **One-Address Format**: Frees one 10-bit address field.
  Total possible 1-address instructions = $7 \times 2^{10} = 7 \times 1024 = \mathbf{7,168\text{ instructions}}$.
* **Zero-Address Format**: If 5,000 one-address instructions are used:
  Unused 1-address patterns = $7,168 - 5,000 = 2,168$ patterns.
  Frees the second 10-bit address field $\implies 2,168 \times 2^{10} = 2,168 \times 1024 = \mathbf{2,220,032\text{ instructions}}$.

### 8. 4-Way Set-Associative Cache TAG Bits Calculation (Dec 2025 Q4a)
**Given**:
* Physical Address Space = 4 GB $= 2^{32}$ bytes $\implies$ **32-bit Physical Address**.
* Cache Capacity = 16 KB $= 16 \times 2^{10} = 2^{14}$ bytes.
* Block Size = 8 words $\times$ 4 bytes/word (32-bit words) = 32 bytes $= 2^5$ bytes.
  $$\implies \text{Block Offset (Byte Offset)} = \mathbf{5\text{ bits}}$$
* Total Cache Blocks / Lines $= \frac{16\text{ KB}}{32\text{ bytes}} = \frac{2^{14}}{2^5} = 2^9 = 512\text{ lines}$.
* Associativity = 4-way set-associative.
  $$\text{Number of Sets} = \frac{512}{4} = 128 = 2^7\text{ sets} \implies \text{Set Index} = \mathbf{7\text{ bits}}$$
* **Number of TAG bits**:
  $$\text{TAG} = 32 - (\text{Set Index} + \text{Byte Offset}) = 32 - (7 + 5) = 32 - 12 = \mathbf{20\text{ bits}}$$

### 9. Hard Disk Drive Latency & Platter Capacity (Dec 2025 Q5a)
**Given**:
* Seek time $= 4$ ms.
* Rotational speed $= 10,000$ RPM.
* Sectors per track $= 600$, Sector size $= 512$ bytes.
* File size $= 2,000$ sectors (each sector access requires a separate seek).
* One side of platter contains 128 tracks.

#### (i) Total Time to Read File:
1. Time for one complete rotation:
   $$T_{rot} = \frac{60\text{ seconds}}{10,000} = 0.006\text{ s} = 6\text{ ms}$$
2. Average rotational latency:
   $$\text{Rotational Latency} = \frac{T_{rot}}{2} = \frac{6\text{ ms}}{2} = 3\text{ ms}$$
3. Transfer time per sector:
   $$\text{Transfer Time} = \frac{T_{rot}}{600} = \frac{6\text{ ms}}{600} = 0.01\text{ ms}$$
4. Access time for one sector:
   $$T_{sector} = \text{Seek} + \text{Rotational Latency} + \text{Transfer} = 4\text{ ms} + 3\text{ ms} + 0.01\text{ ms} = 7.01\text{ ms}$$
5. Total time for 2,000 sectors:
   $$\text{Total Time} = 2,000 \times 7.01\text{ ms} = 14,020\text{ ms} = \mathbf{14.02\text{ seconds}}$$

#### (ii) Memory Size of One Platter (One Side):
$$\text{Capacity} = 128\text{ tracks} \times 600\frac{\text{sectors}}{\text{track}} \times 512\frac{\text{bytes}}{\text{sector}} = 39,321,600\text{ bytes} \approx \mathbf{39.32\text{ MB}}$$
*(Or $37.5\text{ MiB}$ using $1024$ radix)*.

### 10. CISC vs RISC Execution Time Comparison (Dec 2025 Q3b)
**Given**: Clock Frequency $f = 4\text{ GHz} \implies \text{Clock Cycle Time } T = \frac{1}{4 \times 10^9\text{ Hz}} = 0.25\text{ ns}$.
* **CISC Processor**:
  - Instructions = 1, Cycles/Instruction (CPI) = 12.
  - Total Cycles = 12.
  - Execution Time $= 12 \times 0.25\text{ ns} = \mathbf{3.0\text{ ns}}$.
* **RISC Processor**:
  - Instructions = 4, Cycles/Instruction (CPI) = 2.
  - Total Cycles $= 4 \times 2 = 8$ cycles.
  - Execution Time $= 8 \times 0.25\text{ ns} = \mathbf{2.0\text{ ns}}$.
* **Comparison**: The RISC processor completes the task **1.0 ns faster** than the CISC processor (a $1.5\times$ speedup).
